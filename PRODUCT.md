# Product: RamCraft

## Register
product

## Users
Ram and friends managing Minecraft worlds on a home server. They need to start worlds, invite players, install packs, inspect the console, and restore backups without Docker knowledge.

## Product Purpose
A working hosting control panel over the existing FastAPI service. Keep live state truthful and preserve every existing management operation.

## Brand Personality
Inventive, grounded, welcoming. A daylight workshop for building worlds: a clear light work surface, graphite navigation, blue tools, and a block-built landscape.

## Anti-references
Neon gamer dashboards, decorative terminal output, fake infrastructure metrics, landing-page sales copy, and controls disguised as decoration.

## Design Principles
1. Worlds and their status come first.
2. One obvious next action, with destructive controls kept secondary.
3. Live information must distinguish loading, disconnected, and empty states.
4. Minecraft character comes from the landscape and small block details; controls stay familiar.
5. A phone can perform the same essential tasks as a desktop.

## Accessibility & Inclusion
WCAG AA contrast, keyboard-operable controls, visible focus, labeled fields and dialogs, reduced-motion support, and responsive layouts.
