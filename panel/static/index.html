New world

Drop in a world .zip from Planet Minecraft, MinecraftMaps or CurseForge Worlds. RamCraft unpacks it as the world and boots a server on the version you pick.

Drop the map .zip here, or click to choose

Adventure maps are built for one exact version — pick the one the map says.

Assemble your own pack. Pick the loader and version, add mods, and RamCraft installs them plus their dependencies. When it's running you can download a .mrpack from Manage that opens straight in the Modrinth app — so your client matches the server exactly, with no hunting for the same files.

CurseForge-only packs (All the Mods, RLCraft, DawnCraft…) can be installed without an API key — download the pack's Server Pack zip from its Files tab in your browser and drop it here. The key is only needed if you want RamCraft to fetch packs by URL automatically.
